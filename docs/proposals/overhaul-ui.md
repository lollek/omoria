The user interface is old and limited to old computer terminals.
Since we have more screen space we should make use of that to make the game more smooth.
Some ideas below. Consider flexibility. It would be nice to make it possible to switch in the future if I change my mind.
I'm unsure how much we need to connect the GUI with the "server", or if it's possible to separate.

## Terminal split screen

Have the terminal be split into parts, upper left is the game (dungeon). Possibly keep the single line of info there
Below we have an action log, with some kind of scrolling history. Maybe move the single line of info currently at the top of the screen here as well.
To the upper right we have a list of equipped items.
Below that we have the inventory listed.
Below that maybe we have a list of visible monsters, so we dont have to 'look' as much.
Example: https://www.amirrorclear.net/flowers/game/sil/screen4.png

## Modern UI

Maybe we should migrate to a modern GUI instead and have something similar as above. That would open up the possibility of
clicking items, or hovering over enemies, etc.
